# MEMENTO MORI

A ten-episode dual-timeline prestige drama by **Paul Murphy**, developed with **Canyon House Pictures**. The brief combines sharp family estate mystery with grounded historical civil rights drama.

## Current status

The repository contains the project team configuration and development working documents. The original treatment is retained locally and excluded from this public repository pending explicit publication approval. Development diagnosis is the next assignment and requires that local source. The bible, pilot and completed series package have not been written. Approximately hour-long episodes and limited-series positioning remain proposals.

**Screenplay format: Fountain (.fountain).** All screenplay drafts, revisions and scripted sample scenes use Fountain; reader PDFs are exported from the approved Fountain master. FDX is excluded.

## Working with Squad

Open this repository with the installed Squad agent. The existing Squad 1.1.0 scaffolding is retained, with a repository-local team and local state backend. Try: **Alex, coordinate the development diagnosis described in development/brief/first-assignment.md.**

Paul retains final creative authority. Routine work proceeds within the brief; consequential story changes and milestone approvals go to Paul. The first assignment ends at creative-brief review before episode or pilot drafting.

## Validation

Run `node scripts/validate-development.mjs` for project consistency, document links, source integrity, roster, Fountain policy and identity-pair checks. With Squad installed, run `squad health --json` and `squad doctor` for native setup checks. These checks do not constitute creative approval, historical verification or screenplay rendering validation.
