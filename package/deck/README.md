## Presenting

Open the HTML in a modern browser. Use the visible **Previous** and **Next** buttons, the left/right arrow keys or Page Up/Page Down. Home selects the cover; End selects the final slide. **Ending** jumps to slide 15, where spoilers begin. The slide count remains visible. A `#slide-N` URL fragment can open a particular slide. Browser fullscreen is optional. Desktop slides use a 16:9 frame; small screens reflow the active slide into a taller reading layout. Without JavaScript the slides remain readable in sequence.

## Reader PDF export

Use **Print / PDF** or the browser's print command. The print stylesheet includes all sixteen slides even if only one is visible on screen. Select **Save as PDF**, **Landscape**, **no margins**, **100% scale**, **background graphics on**, and **headers/footers off**. Use the CSS-defined 13.333 × 7.5 inch paper size when the browser honors it, or a custom size with those dimensions. A browser that forces another paper ratio may add whitespace or scale the deck. Check the resulting PDF for sixteen pages and legible text before using it as a delivery copy. The HTML is the editable source; an exported PDF is a derived reading copy.

For a spoiler-free presentation stop after slide 14. To export only the pitch portion, select pages **1–14** in the browser print dialog. Pages **15–16** contain the ending. Never describe a page range export as the complete deck.
