# Required screenplay format: Fountain

All pilot and episode screenplay drafts, scripted sample scenes, revisions and editable screenplay deliveries use UTF-8 Fountain files with the .fountain extension. Do not create, request, exchange or deliver FDX files.

Charlie owns the authoritative screenplay source. Reviewers reference its version; revisions and PDF annotations are applied to that source before the next reader PDF is exported. Deliver the matching .fountain file alongside each final screenplay PDF.

Check title page, scene headings, action, character cues, dialogue and pagination in the exported PDF. A plain-text file extension check does not validate screenplay layout. Choose an available Fountain-capable editor/renderer when drafting begins and record the actual export method and results. No renderer or rendering validation is claimed by setup.

Prose outlines, bibles and research documents may use Markdown or another appropriate document format. The Fountain requirement applies to scripted screenplay material.
