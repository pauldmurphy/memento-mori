# Story canon and continuity

Maya owns these records. No story revision is approved merely because it appears here.

Use statuses: explicit-brief, source-backed, proposed, approved-canon, documented-fact, unverified or contested. Fiction canon and historical/legal evidence remain distinct. Assign stable IDs and identify source location or approval provenance.

[characters.csv](characters.csv) records ages/relationships; [chronology.csv](chronology.csv) records events in story order; [reveals.csv](reveals.csv) records discovery order and knowledge changes. These are header-only working templates awaiting diagnosis.
